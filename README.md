# صور شاشة زمان

صور موقع [شاشة زمان](https://cimaeg.github.io)، وتُنشر على `https://cimaeg.github.io/img/`.

| المجلد | المحتوى | مثال |
|---|---|---|
| `posters/` | أفيشات الأفلام، باسم الفيلم نفسه في `data/films.json` | `posters/al-ard-1970.webp` |
| `people/` | صور الممثلين والمخرجين، بأسماء إنجليزية | `people/naguib-el-rihani.webp` |
| `other/` | أي صور أخرى للموقع | |

## القواعد

- كل الصور بصيغة **WebP**.
- الأفيش بعرض 900 بكسل، وصورة الشخص بعرض 700 بكسل، بجودة 84 تقريبًا.
- أسماء الملفات بحروف إنجليزية صغيرة وشرطات، بلا مسافات.
- عند استبدال صورة بأخرى، يُفضَّل تغيير اسم الملف (مثل إضافة `-v2`) حتى لا يعرض المتصفح النسخة القديمة.

## الربط بالموقع

- الأفيش: في `data/films.json` داخل مستودع الموقع، يُكتب `"poster": {"status": "custom", "url": "posters/<اسم-الملف>.webp"}`.
- صورة الشخص: في `data/people.json` يُكتب `"الاسم": {"photo": "people/<اسم-الملف>.webp", "focus": "50% 22%"}`، و`focus` موضع الوجه داخل الإطار الدائري.
